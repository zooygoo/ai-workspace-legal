개인정보처리방침 / Privacy Policy

AI Workspace · 시행일 2026-11-08 · 홈

1. 서비스 성격

AI Workspace는 개발자 본인 한 명이 자기 업무를 관리하려고 만든 개인용 도구입니다. 다른 사용자를 받지 않으며, Cloudflare Access로 개발자 본인 계정만 접속할 수 있습니다.

2. 접근하는 Google 데이터

  • Gmail(읽기, 메일 상태 변경, 메일 보내기): 받은 메일 목록과 내용을 화면에 보여줍니다. 읽음 표시, 보관, 별표, 휴지통 이동, 답장 전송은 사용자가 버튼을 누를 때만 실행합니다.
  • Google Calendar(읽기, 일정 쓰기): 일정을 화면에 보여주고, 사용자가 직접 입력했을 때만 일정을 만들거나 고칩니다.
  • Google Drive(파일 정보 읽기 전용): 파일 이름과 폴더 구성만 읽습니다. 파일 내용은 읽지 않습니다.

3. 저장하는 정보

Google 연결 정보(접근 토큰)는 암호화해서 Cloudflare의 저장소에 보관합니다. 메일 본문과 파일 내용은 저장하지 않습니다. 화면 표시를 위한 목록과 요약은 짧은 시간만 임시로 보관한 뒤 지워집니다.

4. 이용 목적과 제공

Google에서 받은 정보는 사용자 본인 화면에 보여주고 사용자가 요청한 동작을 처리하는 목적으로만 사용합니다. 판매하지 않으며, 광고나 사용자 맞춤 광고에 사용하지 않고, 인공지능 모델의 학습에 사용하지 않으며, 제3자에게 제공하지 않습니다. 법령상 필요한 경우는 예외입니다.

AI Workspace's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 연결 해제와 삭제

언제든 Google 계정의 서드파티 접근 관리에서 AI Workspace의 접근을 해제할 수 있습니다. 해제하면 저장된 연결 정보는 쓸 수 없게 되며, 요청하면 저장소의 연결 정보도 삭제합니다.

English summary

AI Workspace is a single-user personal tool. It reads Gmail, Google Calendar and Google Drive file metadata, and changes mail state, sends replies or edits events only when the owner presses a button. Access tokens are stored encrypted. Mail bodies and file contents are not stored. Google user data is used only to show it to the owner and to carry out the owner's actions; it is not sold, shared with third parties, used for advertising, or used to train AI models.
